# book-to-question skill 打包说明（v5）

## 包结构

```
book-to-question-skill-<日期>-v5.zip
└─ book-to-question/
   ├─ SKILL.md                     # 入口（<8192 字符，加载不截断）
   ├─ references/                  # 各阶段细则 + install.md 装脚本说明
   ├─ scripts/                     # 本 skill 自带脚本（含 install.py / preflight.py）
   ├─ assets/                      # 提示词与拆分/生成脚本副本
   └─ repo-addons/                 # ★ 仓库侧脚本全量镜像（安装时按差异替换）
      ├─ INSTALL.md
      ├─ multi_agent/              # 两个流水线 + utils/agent_runner/ensemble_merge + prompts/
      ├─ md/                       # 提示词
      ├─ 补题/                      # 命题官批量生成.py、拆分章节.py、配置/默认-60题2轮.json
      ├─ 根目录脚本                 # run_converter / mineru_batch_converter / qiniu / qrcode …
      ├─ config.example.json .env.example
      └─ qrcode_templates/
```

不含业务数据（`拆书/`、`补题/题目/`、`exports/`、`progress.json`）。普通版**不含** `.env`、`config.json`；`-keys` 版把 `repo-addons/` 之外的 `deps/.env`、`deps/config.json` 一并放入（权限 600），仅限可信环境。

## 首次安装

1. 解包，把 `book-to-question/` 放到仓库 `.claude/skills/` 下（DSH 用 `.dsh/skills/`，可软链）。
2. 在仓库根跑差异预览：

   ```powershell
   .venv\Scripts\python.exe .claude\skills\book-to-question\scripts\install.py --dry-run
   ```

3. 确认后去掉 `--dry-run` 执行；再跑 `preflight.py` 自检，用 `--emit detail|compact` 取本仓库可用命令。

替换规则：缺失→新增；内容不同→备份到 `.book-to-question-backup\install-<时间戳>\` 后替换；相同→跳过。二次运行全 `SAME`。

## 更新已有 skill（重要）

普通包**不含** `deps/.env`、`deps/config.json`。**不要删除整个 skill 目录再替换**，否则会把本地密钥和配置一起删掉。请用覆盖式解压：

1. 先备份整个现有 skill 目录：

   ```bash
   mkdir -p .book-to-question-backup/skill-<时间戳>
   cp -a .claude/skills/book-to-question .book-to-question-backup/skill-<时间戳>/
   ```

2. 解压时覆盖到 `.claude/skills/`，不要先删旧目录：

   ```bash
   unzip -o book-to-question-skill-<日期>-v5.zip -d .claude/skills/
   ```

   Windows PowerShell：

   ```powershell
   Expand-Archive -Force book-to-question-skill-<日期>-v5.zip -DestinationPath .claude\skills\
   ```

3. 确认 `.claude/skills/book-to-question/deps/.env` 和 `deps/config.json` 还在；如果新包覆盖后缺失，从第 1 步备份拷回。

4. 在项目根跑差异预览，确认 `ADD` / `REPLACE` 后再执行：

   ```bash
   .venv/bin/python .claude/skills/book-to-question/scripts/install.py --dry-run
   .venv/bin/python .claude/skills/book-to-question/scripts/install.py
   ```

   - `install.py` 会更新 `repo-addons/` 里的受管文件（含 `补题/配置/默认-60题2轮.json`），替换前自动备份到 `.book-to-question-backup/install-<时间戳>/`。
   - 不会碰根目录 `.env`、`config.json`、`book.json`，也不会碰 `补题/题目`、`补题/详细版`、`补题/拆分后` 下的成品。

5. 跑 `preflight.py` 自检。

## 参数能力表

| 参数 | 需要 | 旧仓库没装 addons 时 |
|---|---|---|
| `--limit-merge` | 新版 `chapter_pipeline*.py` | 报 `unrecognized arguments`；`preflight --emit` 会自动省略 |
| `--split-by-section` | 新版 `chapter_pipeline1.py` | 同上；`compact_stage.py run` 会自动过滤 |
| `--limit-kimi` | 已失效（Kimi 生成默认关闭） | 两个脚本都不写它 |
| `--limit-deepseek/--limit-doubao/--max-workers/--chapter-max-workers` | 老版也有 | 可用 |

## 回滚

把 `.book-to-question-backup\install-<时间戳>\` 里的文件按相对路径拷回仓库。skill 目录本身用 `.book-to-question-backup/skill-<时间戳>/book-to-question` 还原。

## 重新打包

仓库根（有 `tools/build_skill_package.py` 时）：

```bash
.venv/bin/python tools/build_skill_package.py --version v5
.venv/bin/python tools/build_skill_package.py --version v5 --with-keys
```

产物写到 `~/Desktop`；脚本会检查普通包不含 `.env`/`config.json`，并打印文件数与大小。
