# 故障处理

| 现象 | 处理 |
|---|---|
| tkinter 弹窗不出现 | 用阶段 4 的 `--config` 非交互方式（`补题\配置\默认-60题2轮.json` 或 `<id><书名>.json`） |
| 语雀 401/403 | Token 失效或缺 `repo:write/doc:write`；退回人工导入 |
| 语雀 422 | 正文含不支持的 HTML；先清洗或人工导入 |
| 语雀 422 `slug invalid` | slug 只允许 ASCII；标题含中文时脚本已自动转成 `doc-<hash>`，仍报错就检查是否有超长/非法字符 |
| 「创建分组后仍找不到该节点」 | 语雀 TOC 回读有缓存延迟；确认分组已建后直接重跑同一命令 |
| 上传报成功但分组内少 1 篇 | 同样是 TOC 延迟，稍后复查；若顶层出现同名 `[DOC]`，说明上次 422 留下孤儿，先删该 doc 再重跑 |
| 选项均衡大量「解析含无法映射的字母引用」 | 制图/几何题解析里的 `A点`、`H面`、`a′` 不是选项引用；`_remap_parse` 已按术语后缀排除，仍报错时看该题解析是否有真正的裸字母 |
| `--dir` 传出一堆 `.source/.merged` | 漏了 `--include "*_full*.md"`；脚本虽会自动跳过中间产物，仍应显式指定 |
| `find_source_md` 多命中 | 清理 `补题/详细版/`，同 id 只留一个 |
| 失败章节 JSON 不是数组 | 它存的是模型原文；确认后删除该 json 再重跑 |
| `_failed.txt` 存在 | 该章重新跑，校验通过前阶段 4 不能标完成 |
| organizer 把目录删了 | 先 `--backup-existing`，不要直接删；已删从 `.bak-时间戳` 恢复 |
| Windows 路径含中文/空格 | 全部加双引号；`-` 开头的参数放在路径前 |
| 详细版 merge 出重复章/丢节 | 按 [detail.md](detail.md) 的顺序跑 `clean_detail.py` → `supplement_detail.py`，都先 dry-run |
| 公式 ERROR 未修就想上题 | 不允许；`check_formulas.py` 的 ERROR 必须清零才进阶段 4 |
| 详细版里 `\(...\)` 不换行、超出边界 | 跑 `fix_render.py --file <详细版> --apply` 统一转成 `$...$`；新流水线拼接时已自动归一化 |
| 每章题数明显少于 60×2 | 两轮去重会略低，偏差 >20% 属异常：看 `题目/<书>/.分次/` 是否有失败轮次 |
| `_failed.txt` 存在，但不知道重跑哪章 | 逐行看失败记录定位章节 → 把该章有问题的 `.分次/<章节>.N.json` 移到 `.分次/.重出/` 留档 → 重跑 `命题官批量生成.py`；欠费/网络错误可直接原样重跑，不用删 |
| `balance_report.json` 显示跳过率 >10% | 阶段 4 已写进 `_failed.txt`；看 `reasons`：多为解析里含无法映射的字母引用。改掉该题解析的裸字母，或把该题移入 `.重出/` 后重跑 |
| 校验报「选项长度泄露」 | 正确项 ≥ 最长干扰项 ×1.45 即判错（单题硬错误）；重出该知识点，或在提示词特殊要求里加「正确项与干扰项长度相当」 |
| 校验报「花括号紧贴 `$`」 | `${x\|x>2}$` 这类集合/数列写法中 `${` 会被渲染器当占位符；在花括号前加反斜杠：`$\\{x\|x>2\\}$`（JSON 源）→ 入库 `$\{x\|x>2\}$` |
| 校验报「公式花括号不配对」 | 常见于 `$A={x$ \| $x^2>0}$` 这类 `$` 用错：整段应包在一个 `$...$` 内，集合花括号转义为 `\{...\}` |
| 校验报「LaTeX 反斜杠重复」 | JSON 多转义了一层，解析后仍是 `\\frac`；JSON 源应写 `\\frac`（两个反斜杠），入库为 `\frac` |
| 校验报「Unicode 根号」 | 模型把根号写成 `√`，只能覆盖一个字符且横线不显示；`√x` 改 `$\sqrt{x}$`，`√(x+1)` 改 `$\sqrt{x+1}$`，立方根用 `$\sqrt[3]{x}$` |
| 校验报「数学环境里的中文」 | `$U_{相}$`、`$2a=4，a=2$` 这类写法把中文/全角标点放进了数学环境；改成 `$U_{\text{相}}$`、`$2a=4\text{，}a=2$` |
| 校验报「KaTeX 解析失败」 | 用 `check_katex.py --file/--questions-dir` 复现；按报错位置补全参数、删未定义命令、把 `%` 移出数学环境 |
| 提示「跳过 KaTeX 渲染检查」 | 本机没有 node 或 katex；在仓库根 `npm i katex`，或设 `KATEX_PATH` / 传 `--katex-path` |
| 想批量自动修渲染问题 | `fix_render.py --file/--dir/--questions-dir ... --apply`；默认 dry-run，写盘前备份。只处理可确定的问题，缺参数等解析错误仍需人工或模型 |
| 规则修不掉的 KaTeX 解析错误 | `fix_render_llm.py` 逐条调 DeepSeek（需 `DEEPSEEK_API_KEY`，默认≤20 条）；每条修完重新过 KaTeX，模型拿不准会保留 `__UNFIXABLE__` 等人工 |
| 集合式被 `$` 拆成两段 | `fix_render.py` 会自动合并同一行内的 `$A={x$ \| $x^2>0}$`；跨行或找不到闭合括号的仍会保留，需人工处理 |
| 校验报「判断题偏置」 | 本批「是」过多；重出判断题，或人工把一半改写为「否」并保持难度档位 |
| 校验报「根题干不足 150 字」 | 组合题素材太短；补背景信息或换素材，不要只加套话凑字数 |
| 校验报「同章/跨章近似题」 | 相似度 ≥0.90 为错误、0.60–0.90 为警告；保留一道，其余换素材重出 |
