# 命题配置与校验

## 用哪份提示词

- **上题用** `md\命题官提示词系统 V3.2.md`（正文标题写的是 V3.3，以正文为准）。
- `md\命题提示词系统 V1.2.md` 是「章末练习/图书出版」产品线，不是本流程。
- 120 题/40 题一批是外层工作流约定，不写在 V3.2 里。

## 配置 JSON

```json
{
  "counts": {
    "单选题": {"简单": 8, "中等": 4, "困难": 3},
    "多选题": {"简单": 8, "中等": 4, "困难": 3},
    "判断题": {"简单": 8, "中等": 4, "困难": 3},
    "组合题": {"简单": 3, "中等": 2, "困难": 2},
    "填空题": {"简单": 3, "中等": 1, "困难": 1},
    "简答题": {"简单": 2, "中等": 1, "困难": 0}
  },
  "ratio": "基础题约60%，综合题30%，情景题10%",
  "special": "",
  "overwrite": false,
  "concurrency": 3,
  "rounds": 2
}
```

上例每轮 60 题，两轮共约 120 题（去重后略少）。

- 六个题型键**必须齐全**：单选题、多选题、判断题、组合题、填空题、简答题。
- `counts` 合计 = 每轮题量；`rounds` = 每章跑几轮。
  - `rounds: 1`：只跑一批；
  - `rounds: 2`：两批分别落盘，再按题干相似度 ≥0.60 去重合并，适合目标 ~120 题/章。
- `overwrite` 默认 `false`：续跑只补缺失的轮次，不重跑已完成的。
- 每章题量按「拆分后的每个章节 md」计算；原章拆成多份时，每份各自出题。
- 每本书开始时问：每章总题量、每轮题量、轮数、题型×难度配比、特殊要求。

## 题目字段约束（V3.2）

| 字段 | 要求 |
|---|---|
| `know_id` | 整数，等于启动指令里的知识点 ID |
| `type` | `choice` / `multiple` / `judge` / `fill` / `short` / `group` |
| `title` | 选择/多选/判断用 `（    ）`；填空用全角下划线；组合题根题干 ≥150 字 |
| `tags` | 原样使用「书名-第N章…」，不得自创 |
| `options` | choice/multiple 必填，其余 `[]` |
| `subs` | 仅 group，2–5 个小题；小题不带 tags/difficulty |
| `answer` | 单选字母；多选升序字母串；判断「是/否」；fill 必须是 `""` |
| `source` | `《书名》-章节` |
| `parse` | 解析/标准答案；group 根为 `""` |
| `difficulty` | 0.2–0.9，1 位小数 |

硬规则：

- `title`/`parse` 禁止「教材、课本、根据所学」等来源指代。
- 禁止图片/图表依赖，禁止「如上图/见下图/见下表」。
- 字符串行首 `#` 必须写成 `\#`（JSON 里是 `\\#`）。
- 英文双引号必须转义或改中文引号。
- 只输出一个 JSON 数组，不要代码围栏和说明文字。

## `validate_questions.py` 会查什么

会成为**错误**：

- 章节 JSON 不是合法数组（失败章节通常存的是模型原文）。
- `know_id` 不等于当前书 id。
- `type` 非法。
- `title` 为空；非 group 的 `parse` 为空。
- `source` 为空。
- `title`/`parse` 含来源或图片指代用语。
- `difficulty` 不是 0.2–0.9。
- choice/multiple 的 options 少于 2 项或 answer 为空。
- judge 的 answer 不是「是/否」。
- fill 的 answer 不是 `""`。
- group 的 subs 不在 2–5 个。
- 存在 `_failed.txt`。
- `all.json` 题数与章节合计不一致。

会成为**警告**：

- `tags` 与 `书名-章节名` 不一致。
- `source` 没有以 `《` 开头。
- 行首裸 `#`。
- `difficulty` 不是 1 位小数。
- choice answer 不是单个字母；multiple 未升序去重。
- group 根题干不足 150 字。
- 每章题数与 `counts × rounds` 偏差 >20%（两轮去重后会略低于理论值）。
- 没有 `all.json`。
