# 检查清单

逐项过，不要跳。每项都要给出「通过 / 有问题（附页码或文件名）」。

## 阶段 1：拆书

### 拿到书先查

- [ ] 总页数是否完整，有没有缺失页。
- [ ] 页码是否错乱（缺号、重号、倒序）；有就**先反馈，不继续拆**。
- [ ] 绪论、附录里如果有知识点，必须保留，不能当废页丢掉。
- [ ] 书末习题如果带答案，保留，后续上到系统题库。

### titles.txt

- [ ] 标题数 = 页码范围数。
- [ ] 每行格式 `<id>-<书名>-第N章-章节名`。
- [ ] 页码范围是 **PDF 页号**（印刷页 + 偏移量），1-based 闭区间。
- [ ] 最后一行的范围用英文逗号分隔，例如 `11-19,20-34,35-52`。
- [ ] 偏移量已经用户确认。

### 40 页拆分

- [ ] 原章 ≤40 页：一章一份。
- [ ] 原章 >40 页：按小节顺序合并，每份 ≤40 页。
- [ ] 每份用新节号 + 汇总名：`...-第N章-章名-第1节-<汇总名>`。
- [ ] 不再把原节名拼进文件名。
- [ ] 单个小节本身 >40 页：已停下问用户，没有擅自拆。
- [ ] 拆分计划已打印给用户确认。
- [ ] `verify` 没有重叠、越界、超页；内部空隙已解释（封面/目录/附录）。

### 拆完

- [ ] 章节数与目录一致，无遗漏。
- [ ] 绪论/附录已保留。
- [ ] 输出 PDF 命名和页数正确。
- [ ] 语雀原书分组已建/已上传（见 manual-steps.md）。

## 阶段 2/3：详细版校对

- [ ] 章节是否有遗漏；和 `000-文件索引.md`、`book.json.chapters` 对得上。
- [ ] 内容是否流畅，有没有截断、重复、错序。
- [ ] 删除「参考图 1-10」「例图」这类指代文字。
- [ ] 公式是否完整、能否渲染；已跑 `check_formulas.py`，没有 ERROR。
- [ ] `check_formulas.py` 的 WARN（行内 `$` 截断、`\tag`、分隔符混用）已人工抽查。
- [ ] 表格格式是否正确、能否正常显示。
- [ ] 例题：带答案的保留；不带答案的删除。
- [ ] 图片位置是否在对应正文附近。
- [ ] 图片比例：默认 `img_width_pct=50`，按图片大小逐个调整（过大/过小都要改）。
- [ ] 教材案例题图片：辨认不清时对照原书，补文字说明。
- [ ] 标题层级：每份只有一个 `## 第X章`；其余按 `###/####/#####` 分级。
- [ ] 已跑 `normalize_headings.py`；`##` 数量不为 1 的文件必须修。
- [ ] 「解：」「答：」「作图：」这类正文没有被误当成标题。
- [ ] 详细版的 `##` 数量 = `book.json.chapters` 数量；没有同章重复。
- [ ] 每条目录节（X.Y）在详细版里都能找到；缺失时先跑 `supplement_detail.py`。
- [ ] 已跑 `clean_detail.py`，没有 `## 8.2`、`## # 8.1` 这类跑偏标题。
- [ ] 产物是 `exports/multi_agent/final/书籍库/<id>-1 <书名>.md`。
- [ ] 语雀「详细版」已上传。
- [ ] 9401 后台用**原始 markdown** 上传，不要先从语雀复制。

## 阶段 4：上题

- [ ] 正文来源：优先详细版；缺失才回退 `_full.md`。
- [ ] `补题/详细版/<id><书名>.md` 只有一个同 id 文件。
- [ ] `prep_questions.py` 没有报「节标题出现在 ## 层」。
- [ ] 命题配置 `counts` 六个题型齐全，合计 = 本批题量。
- [ ] 轮数符合预期：`rounds=1` 单批，`rounds=2` 两批合并去重（约 120 题/章）。
- [ ] `overwrite=false`，续跑只补缺失轮次。
- [ ] 两轮都已落盘到 `.分次/`，合并后的每章 JSON 题数在目标附近。

## 阶段 5：精简版（可选）

- [ ] 输入是 `final/书籍库/<id>-1 <书名>.md`（详细版），不是原书 `_full.md`。
- [ ] 已跑 `compact_stage.py prepare`，输入在 `精简版-按章/<id>/<id>-1 <书名>.md`。
- [ ] 产物 `final/精简版/<id>-2 <书名>.md` 存在且非空。
- [ ] `##` 数量与详细版一致；因标题规范化产生的差异已解释。
- [ ] 无空章、无重复标题。
- [ ] 体积比明显小于详细版：>100% 说明没压缩，<5% 可能内容缺失。
- [ ] 已上传语雀「精简版」分组（先 dry-run 再 `--apply`）。
- [ ] 每章都有合法 JSON 数组；失败章节不是合法 JSON。
- [ ] `_failed.txt` 不存在。
- [ ] `validate_questions.py` 通过。
- [ ] 第三批（新教研后台）和题库录入按 manual-steps.md 执行。
